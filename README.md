# AI-Experiments

This repository contains experiments and projects related to Artificial Intelligence.

## Experiments

### MCP-Playwright SauceDemo Automation
Located in `mcp-playwright-saucedemo/`

An automation experiment using Playwright to interact with the SauceDemo website. Demonstrates:
- Web automation with Playwright
- Form filling and button clicking
- Error handling and screenshot capture
- Navigation waiting and URL verification

**Features:**
- Automated login process on SauceDemo website
- Console logging of each automation step
- Screenshot capture for verification
- Error message detection and reporting

See the experiment's README for detailed usage instructions.
