# AI-Experiments

This repository contains experiments and projects related to Artificial Intelligence, including a comprehensive Cypress testing framework for web application testing.

## Projects

### 🧪 Cypress Testing Framework
A complete end-to-end testing framework built with Cypress, featuring:
- **UI Testing**: Interactive element testing, navigation, and user workflows
- **API Testing**: REST API endpoint testing with full CRUD operations
- **Form Validation**: Input validation, accessibility, and user experience testing  
- **Advanced Scenarios**: Performance testing, session management, and error handling
- **Visual & Accessibility**: Screenshot testing, responsive design, and a11y compliance

#### Quick Start
```bash
# Install dependencies
npm install

# Open Cypress Test Runner (interactive mode)
npm run cypress:open

# Run all tests (headless mode)
npm test
```

See the detailed [Cypress Framework Documentation](./cypress/README.md) for comprehensive usage instructions.

## Testing Framework Features

- ✅ **Cross-browser testing** (Chrome, Firefox, Edge)
- ✅ **API testing** with response validation
- ✅ **Visual regression testing** with screenshots
- ✅ **Accessibility testing** (WCAG compliance)
- ✅ **Performance monitoring** (Core Web Vitals)
- ✅ **Mobile responsive testing** (multiple viewports)
- ✅ **Data-driven testing** with fixtures
- ✅ **Custom commands** for reusable test logic
- ✅ **CI/CD ready** for automated testing pipelines
